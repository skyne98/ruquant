Let's build a small Markdown-to-HTML converter in Python, step by step. Start with the basics.

Create a package `mdlite` (a directory `mdlite/` with `__init__.py`) exposing `to_html(text: str) -> str`:

- A blank line (empty or only whitespace) separates blocks.
- A line starting with 1 to 6 `#` followed by a space is a heading: `## Some title` becomes `<h2>Some title</h2>`. A
  heading line is always a block of its own, even without blank lines around it. `#Title` (no space) and 7 or more
  `#` are ordinary text.
- Any other run of consecutive non-blank lines is a paragraph: each line is stripped and the lines are joined with a
  single space, `<p>Hello world</p>`.
- Escape `&`, `<` and `>` in text as `&amp;`, `&lt;` and `&gt;`.
- The output is the block elements joined with `\n`, with no trailing newline. Empty input gives `""`.

Example: `"# Title\nSome\ntext\n\nMore"` gives `"<h1>Title</h1>\n<p>Some text</p>\n<p>More</p>"`.

Add pytest tests in `tests/`. The tests run with `python -m pytest`.
