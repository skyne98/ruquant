Now lists and code blocks:

- Lines starting with `- ` or `* ` are unordered list items; lines starting with a number, a dot and a space
  (`1. `, `10. `) are ordered list items. Consecutive items of the same kind form one list:
  `"- a\n- b"` gives `"<ul>\n<li>a</li>\n<li>b</li>\n</ul>"` (and `<ol>` for ordered items). Inline formatting
  applies inside items. A list ends at a blank line, at an item of the other kind, or at a line that isn't an item
  (that line starts a new paragraph). An item line also ends a paragraph right before it.
- Fenced code blocks: a line ```` ``` ```` (optionally followed by a language, ```` ```python ````) opens a block and
  the next line that is exactly ```` ``` ```` closes it. The lines in between are output verbatim (escaped, but no
  formatting, indentation kept), joined with `\n`: `<pre><code>...</code></pre>`, or
  `<pre><code class="language-python">...</code></pre>` with a language. Blank lines inside don't end the block. A
  block that is never closed runs to the end of the input.
