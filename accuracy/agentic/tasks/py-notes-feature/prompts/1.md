Add a `search` command to the notes CLI:

    python -m notes search QUERY [--tag TAG]... [--since YYYY-MM-DD]

- QUERY matches the title or the body, case-insensitively, as a substring. An empty QUERY ("") matches every note.
- `--tag` can be given several times; a note must have all the given tags.
- `--since` keeps notes created on or after that date.
- Print the matching notes exactly like `list` does (same line format, newest first) and exit with 0.
- When nothing matches, print `no matches` to stderr and exit with 1.

Document it in the README and add tests. The tests run with `python -m pytest`.
