Accounts can be soft-deleted (`users.delete_user` sets `deleted_at`), but most of the code still treats deleted users
as active: they can borrow books, get overdue emails, and `whois` finds them. Please refactor the user lookup:

1. Replace `users.get_user(id)` with `users.fetch_user(user_id, *, include_deleted=False)`. By default it returns
   `None` for deleted users; with `include_deleted=True` it returns them too. Remove `get_user` entirely; don't keep
   an alias.
2. Update every caller. Deleted users must not be able to borrow (`lend` raises `LoanError`), must not get overdue
   emails, and `whois` must report them as unknown. Their fines must still be counted by `fines.outstanding`, and the
   staff reports in `admin.py` must keep listing deleted accounts as they do now. `require_user` and `is_staff` should
   treat deleted users as missing.
3. Update the tests and add tests for the deleted-user behaviour.

The tests run with `python -m pytest`.
